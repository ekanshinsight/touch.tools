## Third-party pieces

The app installs its Python dependencies from PyPI at setup time (`websockets`,
`pynput`, `mss`, `Pillow`, `qrcode`). They are not bundled in this repository and
each keeps its own licence.

## Keys and accounts

No model key, account detail or personal path is stored in this repository. A key
typed into the interface stays in that device's browser storage and is never
committed, logged or displayed again. When an endpoint refuses browser calls
(OpenCode Go), the request is relayed once through the local PC, which does not
store it.
